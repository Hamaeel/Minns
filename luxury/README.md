# Minns luxury version

Built from the Figma frames "0" to "7439425" (1282 x 720 each) in the TechoMatrix Work file.

- Open `index.html` in a browser. No build step.
- Desktop (wider than 820px) scales the Figma frame to the window width, so the layout matches the design at every desktop size.
- Phones and small tablets get a stacked layout.
- `assets/css/style.css` holds all styles, `assets/js/main.js` the intro animation, boat switcher, harbour scroll and FAQ.

Content is real Minns info only (fleet, FAQ answers, phone, email, hours).
